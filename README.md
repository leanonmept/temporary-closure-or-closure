# 장기요양기관 휴·폐업 안내 v23

- 수급자 작성 예시를 김철수·이영희·박영수·홍길동 4명으로 확대했습니다.
- 장기요양인정번호는 L0000000·L1111111·L2222222·L3333333으로 표시했습니다.
- 각 수급자는 계약서 9매, 제공기록지 52매, 명세서 12매로 통일했으며 총계도 다시 계산했습니다.

- 첫 번째 수급자 예시를 계약서 9매, 제공기록지 52매, 명세서 12매로 수정했습니다.
- 공통서류와 두 번째 수급자 예시를 포함한 총계는 계약서 10매, 기록지 등 110매, 명세서 22매로 다시 계산했습니다.

- 별지 제36호 이관 목록표의 방문요양 작성 예시를 추가했습니다.
- 공통서류는 인정번호 칸에 서류명을 쓰고 ② 기록지 등 칸에 매수를 적는 위치를 표로 표시했습니다.
- 수급자별 연번·인정번호·성명과 계약서·기록지·명세서 매수 기재 예시를 함께 넣었습니다.

- 첫 화면에 `질문 한눈에 보기` 9개 항목을 추가했습니다.
- 질문을 누르면 아래의 해당 답변이 자동으로 펼쳐지고 바로 이동합니다.

- 첫 화면의 `편철방법`과 `기록물 편철 순서 가이드`를 누르면 상황 선택 없이 편철 내용으로 바로 이동합니다.
- 고정 상단 메뉴에 제목이 가려지지 않도록 이동 위치를 보정했습니다.

- 편철가이드 2025·2026 별지서식은 외부 페이지로 튕기지 않고 사이트 안의 큰 PDF 미리보기로 확인합니다.
- 각 서식의 정확한 페이지 범위를 표시합니다.
- 2026년: 별지22 60~61쪽, 별지23 62쪽, 별지24 63~65쪽, 별지24의2 66~68쪽, 별지24의3 69~71쪽, 별지25 72쪽, 별지26 75~76쪽.
- 2025년: 별지22 50~51쪽, 별지23 52쪽, 별지24 53~55쪽, 별지24의2 56~58쪽, 별지25 59쪽, 별지26 62~63쪽.
- PDF 새 창 열기와 공단 규정 원문 버튼을 함께 제공합니다.
- 이전 버전의 휴·폐업/자료이관/대리인/편철 안내 내용은 유지합니다.
