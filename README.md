# 장기요양기관 휴·폐업 안내 v25

## 이번 수정사항

- 편철 가이드에 각 장 우측 하단의 연필 쪽번호 기재 방법을 추가했습니다.
- 서류 항목이 바뀔 때마다 1부터 다시 시작하도록 예시를 넣었습니다.
- 모든 자료는 300매를 기준으로 분권하되, 한 수급자의 자료는 권 사이에서 나누지 않도록 안내했습니다.
- 다음 수급자 자료를 넣으면 300매를 넘는 경우, 해당 수급자 전체를 다음 권으로 넘기는 예시를 넣었습니다.
- 방문간호지시서는 방문간호 급여를 제공한 기관만 제출한다는 안내를 강조했습니다.

## 유지된 주요 수정사항

- 첫 화면의 `편철방법`과 `기록물 편철 순서 가이드`를 누르면 상황 선택 없이 편철 내용으로 바로 이동합니다.
- 첫 화면에서는 이관 목록표 작성 예시와 편철 가이드를 숨기고, 관련 항목을 눌렀을 때만 표시합니다.
- 이관 목록표 작성 예시는 편철 가이드 바로 위에 배치했습니다.
- `질문 한눈에 보기`와 방문요양 이관 목록표 작성 예시를 제공합니다.
- 이관 목록표 예시는 김철수·박영수·이영희·홍길동 4명과 각 수급자에게 연결된 가상 인정번호를 사용합니다.
- 수급자 예시는 김철수·박영수·이영희·홍길동의 성명 가나다순으로 배치했습니다.
- 각 수급자의 예시 매수는 계약서 9매, 제공기록지 52매, 명세서 12매입니다.
- 입력 기능이 없는 안내사이트이므로 개인정보 보호 안내 영역과 하단 중복 문구를 제거했습니다.
- 편철 결과의 불필요한 별지 서식 안내 상자는 제거했습니다.
- 2025·2026년 별지 서식은 사이트 안의 PDF 미리보기로 확인할 수 있습니다.
