# 장기요양기관 휴·폐업 자료이관 안내 v11

## 이번 버전 반영사항
- 참고사이트의 주요 업무영역(신청접수, 제출서류, 편철방법, 자료이관, 제출서식, 확인사항, 질문 모아보기, 기록물 편철 가이드, 지사찾기, 개인정보 안내)을 유지
- 광주전라제주지역본부 표기 삭제
- 폐업/휴업 및 처리유형을 행정용어 중심으로 단순화
- 자료이관: 현재 급여제공 중이면 일부이관 → 접수증 → 종료 후 잔여자료 추가이관 → 이관완료
- 전건 분실: 신청서 + 이관목록표 + 분실·훼손목록표 + 확인서, 과태료 가능성 안내
- 급여제공이력 없음: 최근 5년간 또는 휴업 후 급여제공이력 없이 폐업하는 경우, 신청서 + 이관목록표 + 확인서
- 자체보관: 휴업 시 공단 허가를 받은 경우
- 신청인 서류: 대표자/대리인, 개인/법인 선택형 안내 및 위임장 연결
- 기관 급여종류별 편철 가이드 복수선택
- 확인서/위임장 바로 보기·인쇄
- 개인정보 안내, 공단 지사찾기, 1577-1000 연결
- 홈 화면 추가용 PWA 구성
