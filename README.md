# 장기요양기관 휴·폐업 안내 v30

## 이번 수정사항

- 휴·폐업 이관자료는 기준월을 포함해 총 61개월분을 준비하도록 안내를 추가했습니다.
- 2026년 9월 기준으로 2021년 9월부터 2026년 9월까지라는 계산 예시를 넣었습니다.
- 61개월 안내를 이관자료 화면, 질문과 답변, 최종 체크 항목에 함께 반영했습니다.
- 확인서 안내를 실제 항목인 분실(일부·전부 및 사유), 훼손(일부·전부), 급여제공내역 없음, 기타로 구분해 수정했습니다.
- 확인서를 전건 분실과 급여제공이력 없음에만 작성하는 것처럼 보이던 문구를 바로잡았습니다.
- 기존 서비스워커가 이전 화면을 계속 표시하지 않도록 캐시 삭제용 `service-worker.js`를 포함했습니다.
- `순서대로`는 화면 너비와 관계없이 단어 중간에서 줄이 갈라지지 않도록 고정했습니다.
- 첫 화면 안내 문장이 `순서/대로`처럼 단어 중간에서 갈라지지 않도록 줄바꿈을 개선했습니다.
- 300매 분권 안내에 표지 필수 기재사항(기관명·급여종류·자료 해당 연도·전체 권수 중 현재 권 번호)을 추가했습니다.
- 자료는 표지를 붙여 권별로 고무줄로 묶어 가져오도록 안내했습니다.
- 자료의 연도가 바뀌면 기존 권의 잔여 매수와 관계없이 새로운 권으로 시작하도록 강조했습니다.
- 이관 목록표의 축약 열 제목을 원 서식에 맞는 전체 명칭으로 표시했습니다.
- 편철 가이드에 각 장 우측 하단의 연필 쪽번호 기재 방법을 추가했습니다.
- 서류 항목이 바뀔 때마다 1부터 다시 시작하도록 예시를 넣었습니다.
- 모든 자료는 300매를 기준으로 분권하되, 한 수급자의 자료는 권 사이에서 나누지 않도록 안내했습니다.
- 다음 수급자 자료를 넣으면 300매를 넘는 경우, 해당 수급자 전체를 다음 권으로 넘기는 예시를 넣었습니다.
- 방문간호지시서는 방문간호 급여를 제공한 기관만 제출한다는 안내를 강조했습니다.
- 이관 목록표 공통서류 행의 비고란을 비웠습니다.
- 이영희 계약서는 0매, 비고는 `2025년 계약건`으로 표시하고 계약서 총계를 27매로 다시 계산했습니다.
- 공통서류·수급자·서류종류별 쪽번호 재시작 방법과 0매 처리 예시를 상세히 추가했습니다.

## 유지된 주요 수정사항

- 첫 화면의 `편철방법`과 `기록물 편철 순서 가이드`를 누르면 상황 선택 없이 편철 내용으로 바로 이동합니다.
- 첫 화면에서는 이관 목록표 작성 예시와 편철 가이드를 숨기고, 관련 항목을 눌렀을 때만 표시합니다.
- 이관 목록표 작성 예시는 편철 가이드 바로 위에 배치했습니다.
- `질문 한눈에 보기`와 방문요양 이관 목록표 작성 예시를 제공합니다.
- 이관 목록표 예시는 김철수·박영수·이영희·홍길동 4명과 각 수급자에게 연결된 가상 인정번호를 사용합니다.
- 수급자 예시는 김철수·박영수·이영희·홍길동의 성명 가나다순으로 배치했습니다.
- 계약서는 김철수·박영수·홍길동 9매, 이영희 0매이며 제공기록지 52매와 명세서 12매는 각 수급자에게 동일하게 적용했습니다.
- 입력 기능이 없는 안내사이트이므로 개인정보 보호 안내 영역과 하단 중복 문구를 제거했습니다.
- 편철 결과의 불필요한 별지 서식 안내 상자는 제거했습니다.
- 2025·2026년 별지 서식은 사이트 안의 PDF 미리보기로 확인할 수 있습니다.
